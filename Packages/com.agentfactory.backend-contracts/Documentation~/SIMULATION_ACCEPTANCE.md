## 守恒验收

每个固定步或测试窗口验证：

```text
期初库存 + 买入 + 配方生成
= 期末库存 + 配方消耗 + 销售 + 泄漏 + 丢弃
```

库存覆盖设备缓存、端口缓存和管道流体包。

资金验证：

```text
初始余额 + 所有流水金额 = 当前余额
```

## 确定性验收

所有厂区、设备、任务、Agent、流体包、订单和请求在处理前按稳定字段排序。禁止使用系统时间、未保存的随机数或字典自然遍历顺序决定模拟结果。

比较两次运行的：

- `WorldVersion` 与 `SimulationStepId`
- 余额和完整资金流水
- 所有缓存和流体包数量及位置
- 设备、管道、任务和订单状态
- 故障次数和剧情解锁集合

浮点字段使用统一容差，资金字段必须精确相等。
